## Шаг 4. Размещение — вы (около 10 минут)
Из облачной среды Claude доступ к InfinityFree закрыт, загрузить файлы могу только через вас.
1. Зарегистрироваться на infinityfree.com → Create Account → выбрать поддомен.
2. File Manager → `htdocs` → удалить заглушку → загрузить `index.html` и папку `img`. Если File Manager принимает zip, загрузить архив и распаковать.
3. Включить бесплатный SSL (раздел SSL Certificates).

## Шаг 5. Проверка после запуска — вместе

## Ограничения
- Формы остаются демонстрационными: при приёме реальных данных пациентов хранить их нужно на сервере в Казахстане.
- Домен `.kz` на InfinityFree не подключить (нужен сервер в РК); бесплатный поддомен или домен `.com` — можно.
