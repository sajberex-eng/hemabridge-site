# Как выложить HemaBridge на InfinityFree (≈5 минут)

1. Зарегистрируйтесь на https://www.infinityfree.com (нужен только e-mail).
2. **Create Account** → выберите бесплатный поддомен, например `hemabridge.infinityfreeapp.com`, или подключите свой домен (не `.kz`: для `.kz` нужен сервер в Казахстане).
3. Дождитесь, пока аккаунт станет **Active** (обычно несколько минут).
4. Откройте **File Manager** → папку `htdocs`.
5. Удалите файл-заглушку `index2.html` (или `default.php`), если он там есть.
6. Загрузите `index.html` из этой папки (**Upload** → выберите файл).
7. Откройте свой адрес. SSL можно включить бесплатно в разделе **SSL Certificates**.

Файл один и самодостаточный: шрифты подгружаются с Google Fonts, логотип встроен внутрь.

## Важно

- Формы демонстрационные и ничего не отправляют, поэтому зарубежный хостинг допустим.
- Когда формы начнут принимать данные пациентов, их нужно будет хранить на сервере в Казахстане (закон РК о персональных данных).
- Новые домены InfinityFree иногда 24–72 часа открываются не у всех провайдеров, это нормально.
