# HemaBridge — сайт программы Центра гематологии

Статический сайт (один `index.html` + папка `img/`), без сборщиков и серверного кода.

## Структура
- `index.html` — готовая страница, её и загружать на хостинг вместе с `img/` и `robots.txt`.
- `img/` — иллюстрации (WebP, ~840 КБ суммарно).
- `src/` — исходники редизайна: `original.html` (исходная версия), `style.css`, `hero.html`, `wizard.html`, `extra.js` и `build.py`, который собирает `index.html`.
- `PRODUCT.md` — описание продукта и бриф; `PLAN.md` — план работ; `DEPLOY-InfinityFree.md` — инструкция по размещению.

## Пересборка
```
cd src && python3 build.py
```

## Важно
- Сайт закрыт от поисковиков (`noindex` + `robots.txt`) до официального запуска.
- Формы демонстрационные, данные никуда не отправляются.
